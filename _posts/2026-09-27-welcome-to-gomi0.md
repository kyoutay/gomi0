This is the first entry on the new barebones blog.

### How this blog works

- **No database, no CMS**: Everything is stored as plain Markdown text files in the git repository.
- **Hosted on GitHub Pages**: Pushing a new file automatically rebuilds and deploys the site.
- **Minimalist**: Loads instantly, no trackers, barebones styling.

### How to publish a new post

To create a new entry, just add a new `.md` file to the `_posts/` folder with the naming convention:

```
YYYY-MM-DD-title-of-post.md
```

Give it a simple header at the top:

```markdown
---
layout: post
title: "Title of Your Post"
date: 2026-09-27
---

Your content goes here in standard Markdown...
```

Then commit and push to GitHub. The changes will go live in seconds!
